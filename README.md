## Описание
Интеграция хаба Aqara (M1S/M2/M3 и др.) — русская локализация.
### Возможности
- Датчики качества воздуха
- Бинарные датчики (движение, контакты и т.п.)
- Управление климатом
- Управление шторами/жалюзи
- События
- Управление светом
- Удалённое управление (ИК и т.п.)
- Сенсоры и мониторинг состояния
- Переключатели и вкл/выкл устройства
### Установка
1. Скопируйте папку `custom_components/aqara_bridge/` в каталог `custom_components/` конфигурации Home Assistant.
2. Перезапустите Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → **Aqara Bridge**.
> Установка через HACS: добавьте репозиторий `https://github.com/bezuglyy/AqaraBridge-ru` как Custom repository (категория Integration).

## Description
Aqara hub integration (M1S/M2/M3 etc.) — Russian localization.
### Features
- Air quality sensors
- Binary sensors (motion, contacts, etc.)
- Climate control
- Cover/blind control
- Events
- Light control
- Remote control (IR etc.)
- Sensors and state monitoring
- Switches and on/off controls
### Installation
1. Copy the `custom_components/aqara_bridge/` folder into the `custom_components/` directory of your Home Assistant configuration.
2. Restart Home Assistant.
3. Settings → Devices & Services → Add Integration → **Aqara Bridge**.
> HACS: add `https://github.com/bezuglyy/AqaraBridge-ru` as a Custom repository (category Integration).
