# Aqara Bridge
Кастомная интеграция для [Home Assistant](https://www.home-assistant.io) · версия **2.1.2-ru3**.

|---|---|

| Тип | custom integration |
## Описание
Интеграция хаба Aqara (M1S/M2/M3 и др.) — русская локализация.
## Возможности
- Датчики качества воздуха
- Бинарные датчики (движение, контакты и т.п.)
- Управление климатом
- Управление шторами/жалюзи
- События
- Управление светом
- Удалённое управление (ИК и т.п.)
- Сенсоры и мониторинг состояния
- Переключатели и вкл/выкл устройства
## Установка
1. Скопируйте папку `custom_components/aqara_bridge/` в каталог `custom_components/` конфигурации Home Assistant.
2. Перезапустите Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → **Aqara Bridge**.
> Установка через HACS: добавьте репозиторий `https://github.com/bezuglyy/AqaraBridge-ru` как Custom repository (категория Integration).
